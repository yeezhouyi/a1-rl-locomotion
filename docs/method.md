# 方法与实验设计

目标是在相同速度跟踪任务和相同动力学随机化范围内，比较无条件策略和由历史信息驱动的适应策略。优先取得单种子可运行结果，再完成多种子和消融。算法来源为 [RMA 原论文](https://arxiv.org/abs/2107.04034)，当前实现和原论文的差异见 README。

## 信息流

环境参数 `e = [friction, payload_kg, motor_strength]` 仅供训练中的编码器和监督目标使用。演员输入 `o` 为 45 维：角速度 3、重力投影 3、速度命令 3、关节位置偏差 12、缩放关节速度 12、上一步动作 12。历史中的上一步动作已包含策略输出，因此不用另外拼接重复动作。

阶段一同时优化 `z = encoder(e)` 与 `a = tanh(actor(o,z))`。评论家用同样的输入计算价值。普通域随机化基线始终使用零隐变量，网络宽度与教师一致，但不使用环境编码器；这保持主要控制网络容量一致，同时允许教师使用额外信息。

阶段二冻结阶段一的编码器、演员和评论家。适应器读取最近 H 个观测，使用两层一维卷积和池化预测隐变量：`z_hat = adaptation(o[t-H+1:t])`。优化目标是 `mean((z_hat - stop_gradient(encoder(e)))**2)`。收集数据时由 `actor(o,z_hat)` 控制机器人，而不是持续由教师控制。这样适应器会接触自身误差造成的状态。

每次回合结束后清空历史，填入新回合第一帧，避免把上个回合的环境信息泄漏到新回合。重置初期历史不足时使用零填充，这段冷启动也包含在评估中。实际部署策略没有调用 `privileged()`；特权评估模式 `oracle` 是单独入口。

## 控制接口

策略输出 12 维归一化动作，经 `q_target = q_nominal + 0.5 * action` 转换为关节位置目标并限制到关节范围。控制频率为 50 Hz，MuJoCo 内部以 500 Hz 计算 `tau = strength * (30 * (q_target-q) - 0.8 * qdot)`，限制在 `±33.5 * strength` Nm。关节模型自身还存在原模型的被动阻尼与摩擦。

第一版软件试跑曾在 Python 中逐物理步计算 PD；为减少调用开销，当前实现采用 MuJoCo 仿射执行器和一次调用执行 10 个物理步。功率惩罚由逐物理步均值改为控制步末端采样。因此旧的 `smoke_*`、`pilot_*` 仅作为链路排错记录；正式比较使用当前实现重新评估，不将跨奖励版本的训练回报直接比较。

PPO 使用 tanh 高斯策略、包含 tanh 变换的对数概率、GAE、裁剪概率比和梯度裁剪。代码中的熵项是底层高斯的熵正则，并非变换后分布的精确熵。跌倒禁止价值自举；时间到期使用重置前末状态自举，但两种边界都阻止 GAE 传播到下一个回合。

## 怎么解释结果

先检查名义条件下特权策略能否行走。如果特权策略尚未学好，学生表现差不能证明历史适应无效，应先解决阶段一的学习问题。

教师更好但学生较差时，检查历史长度、冷启动、学生访问状态分布和隐变量估计误差。隐变量 MSE 小却控制差时，检查编码器是否输出近似常数，以及演员对微小隐变量误差的敏感性。仅有低 MSE 不能作为适应成功证据。

域随机化基线可能在小扰动范围内与 RMA 相当甚至更好，原因可能包括额外估计噪声、历史窗口滞后和任务对环境信息不敏感。结果应由相同场景和训练种子的对照支持，不预设 RMA 必定胜出。

未见参数组合同时改变多个条件，适合作为压力测试，但不能直接归因于某一个参数。分别报告单因素与组合因素结果。摩擦突变时不清空历史，观察适应滞后；突变仅修改模型参数，保留位置、速度、时间和控制输入。

## 最快交付顺序

1. 单种子阶段一：先得到能完成名义速度跟踪的基线和特权策略。
2. 单种子阶段二：训练适应器，保留完整日志与检查点。
3. 配对评估：名义条件、单参数外推、组合外推、摩擦突变、侧向推扰；至少记录真实跟踪误差与失败。
4. 生成对比视频、训练曲线与失败说明，组成初版展示。
5. 对最有解释力的结论增加独立训练种子和历史窗口消融。

前四步可以形成初版作品，但正式写“提升 X%”之前，需要完成第五步、固定模型选择规则并排除选择偏差。仿真展示不等于真机落地。
