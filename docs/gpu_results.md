# A1 GPU 强化学习实测

基于固定MuJoCo Playground快照适配Unitree A1，使用上游Brax PPO，在RTX 4060 Laptop上完成1024并行训练。平地30M模型首次固定保留集8/8达标；粗糙地形初次续训依赖空间起点，不能称稳定地形泛化。

## 方法与环境

真实JAX `gpu` / `cuda:0`，8188MiB显存，WSL Ubuntu24.04、Python3.12.3、JAX/CUDA插件0.8.2、MuJoCo/MJX/mujoco-warp3.15.0、Brax0.14.2、Warp1.18.0。版本见D盘`environment.json`和`requirements-frozen.txt`。Windows CPU环境只用于资产生成与视频回放。

48维actor含局部线速度，123维特权critic；网络512/256/128，12关节PD目标，50Hz控制、250Hz物理步。继承上游任务逻辑，改写A1初始化及可选起点分布，见[gpu_sources.md](gpu_sources.md)。GPU路线无RMA历史适应器，与旧45维盲行RMA不能直接作算法归因比较。

## 固定指令评估

4场景×2初始seed、每回合20秒，关节±0.03rad偏移、初速0、噪声0、确定性策略、无自动重置。达标要求完整存活且无越界，平面速度向量RMSE<0.2m/s、偏航RMSE<0.3rad/s。跌倒为上游翻转终止、机身z<0.14m或非有限状态。失败后停止累计指标，视频截断。

| 模型 / 测试 | 达标 | 跌倒 | 越界 |
|---|---:|---:|---:|
| 上游奖励约11M / 平地开发集 | 0/8 | 2/8 | 0/8 |
| 修改奖励30M / 平地首次保留集 | 8/8 | 0/8 | 0/8 |
| 平地30M迁移 / 粗糙中央集、容量320 | 5/8 | 2/8 | 0/8 |

| 宽起点追加20M / 旧空间确认集 | 8/8 | 0/8 | 0/8 |

上游奖励模型基本原地站立，存活不等于跟踪成功。修改奖励30M的平地保留集四场景速度RMSE约0.0235、0.0253、0.0340、0.0214m/s。奖励调整同时改变多个权重且预算不同，不能称单变量等预算消融，见[gpu_reward_experiment.md](gpu_reward_experiment.md)。

首次平地保留集seed93000–93007，slow/fast命令0.22/0.5m/s及停走、±0.2rad/s转向反转，与开发命令不同。粗糙地图20×20m、高度缩放0.05m、安全边界±9.5m；从中央起点0.5m/s×20s需要约10m，留量不足，因此保留6/8和两个越界失败。新空间确认固定x=-2m、seed104000–104007、同指令与判据；迁移与续训均4/8，不能声称稳定改进。空间起点与seed同时变化，不能独立归因。

粗糙中央集已用于诊断和训练决策，不再称严格未参与开发的最终测试。所有GPU训练仅seed0，8回合不能证明跨训练seed稳定性。早期`rough_transfer30m_eval`未限制越界，仅保留开发记录，不作为正式粗糙地形结论。

## 修复与存储

- JAX0.11.2移除Brax所需`device_put_replicated`；固定0.8.2后训练成功。显式加入独立`mujoco-warp`依赖。
- Brax恢复nullable initializer触发`KeyError: None`；本地loader保留None语义、恢复保存架构与normalizer，不改第三方安装文件，动作一致验证通过。
- 粗糙`njmax=120`出现`nefc overflow`，中止并弃用该轮。升至320后统一训练/评估容量重跑，未见溢出；启动器出现溢出即标记无效。
- WSL空闲退出会丢loop挂载；启动器同次调用挂载/执行/导出，源码同步先检查挂载。一度误写的两个小源码文件已移至D盘`unmounted_source_recovery`，对应训练未启动。

清理本项目旧环境/缓存3,070,421,821字节，C盘实际空闲从约63.2GiB变为65.2GiB；删除量与空闲增加量不同。记录为`<GPU_STORAGE>/cleanup.json`，未关闭/压缩原WSL，保留旧正式成果。

新增依赖、缓存、训练均在D盘20GiB镜像`<GPU_STORAGE>/training.ext4`；证据在`<EVIDENCE>`。启动器拒绝C盘<25GiB、D盘<15GiB、镜像内部<3GiB的新实验。成果页：https://yeezhouyi.github.io/a1-rl-locomotion/。每轮保留配置、日志、源码哈希、progress、检查点、恢复验证、评估轨迹及视频。

本报告初次地形阶段未验证GPU坡地/台阶；后续已扩展六级3.5cm台阶与6.84°坡面，PPO结合高层航向反馈完成同固定保留集8/8穿越，详见[gpu_course_results.md](gpu_course_results.md)。无真机验证，不能写复杂地形全面成功或完整RMA论文复现。

## 空间覆盖追加实验

确认集失败后，检查上游reset发现训练初始xy仅覆盖±0.5m；追加将其扩大至±3m，保留yaw、初速、奖励、网络和指令分布，并使地图越界终止。宽起点20,029,440步完成，checkpoint恢复动作误差0，日志无约束溢出。训练内部计时328.06秒，外层561.06秒包含冷加载等开销，不能只报前者为完整墙钟时间。

预先固定新`spatial_holdout`为seed116000–116007、起点x=-2m及原保留指令，对冻结平地30M模型直接迁移与宽起点最终模型配对测试。旧104000确认集仅作为开发诊断，不用于选中间检查点。追加采样、训练分布和越界终止同时变化，不能称单变量消融或将收益单独归因于起点覆盖。

新空间保留集实测：直接迁移1/8达标、7/8跌倒；宽起点最终模型7/8达标、1/8跌倒、无越界。失败为fast seed116002，其速度/yaw RMSE约0.52m/s、0.36rad/s；其余7回合完整20秒。旧确认集8/8、无跌倒/越界，但该集已用于诊断，不能与新保留集合并冒充独立15/16测试成绩。新保留集slow/fast/stop/turn成功数分别2/2、1/2、2/2、2/2。

最终宽起点检查点复测平地保留集8/8、无跌倒，说明本次地形续训后仍保留该固定集合的平地技能。完整Linux路径：`runs/rough_wider_reset20m_s0_v2/checkpoints/000020029440`。地形保留评估在`rough_wider_spatial_holdout/result/evaluation.json`，直接迁移对照为`rough_transfer_spatial_holdout/result/evaluation.json`；两者evaluator和environment哈希相同，协议、容量320与初始seed一致。

面试说明见gpu_interview.md（历史实验文件，参见 Release 与公开 evidence），训练回调曲线在D盘成果页，可由`tools/plot_gpu_progress.py`重建。
