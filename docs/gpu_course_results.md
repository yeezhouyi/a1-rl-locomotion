# 坡地和台阶任务：真实穿越与视频

本轮沿用已跑通的MuJoCo Playground任务和Brax PPO，基于此前粗糙地形模型扩展到真实坡面/台阶碰撞。增加专门地形训练，并将速度控制与高层航向反馈分开评估；不是从GitHub下载现成视频。

## 几何与任务

六级3.5cm真实台阶，40cm踏面、总升高21cm，80cm平台后下台阶；6.84°坡、最高24cm、平台后下坡。每种地形通道宽2.4m，验收要求中心保持在±1.1m内防止绕障。36点射线核验几何表面与高度函数最大差0.715mm；足端传感器确实检测台阶/坡面碰撞。证据`geometry_audit/geometry_audit.json`。

台阶直行、台阶变速停走、坡地直行、坡地转向，各2回合。起点x=-1.3，关节±0.03rad，20秒，无自动重置。达标需完整存活、无越界、最终x≥6m（跨过全部上下障碍），平面速度向量RMSE<0.2m/s、yawRMSE<0.3rad/s。出口在无限物理平面上，正式x上界12m；安全范围与障碍穿越分别统计。

## 原始开发与修正

- 旧模型纯yaw-rate指令开发集0/8、无跌倒、8次横向偏离通道，不能称完整任务成功。
- 高层航向反馈首轮2/8、无跌倒、6次出口x=9m越界；其余回合已越过障碍，但未满足20秒。0.5m/s×20秒约需10m距离，因此在正式保留测试前将无限平面出口留量固定至12m，旧结果保留。
- 航向反馈借鉴legged_gym的heading误差转yaw-rate流程，加入本地通道横向误差；增益1.5、横向项0.5、限幅±0.4rad/s。底层PPO不访问新增地图/高度观测，48维输入；高层使用仿真机体yaw和横向位置。必须标注“PPO速度策略＋高层航向反馈”，不作为纯策略新增技能或真机部署。
- 实际碰撞几何的MULTICCD需要双方margin=0，原0.001触发初始化异常；新几何固定zero margin后通过。初始化ConfigDict锁定问题用其官方unlocked上下文增设字段，失败轮未训练，不使用其结果。

## 专门训练

从此前粗糙宽起点最终模型恢复，512并行、64 minibatch、640约束容量；新增30,003,200控制采样步，训练内部462.89秒、外层506.06秒。恢复只加载参数/normalizer，Adam重启；保存后动作一致验证最大误差0，无约束溢出。

训练起点覆盖三通道x[-1.5,5.8]；前进0.25–0.65m/s含10%停止、yaw±0.08。足端净空以地形相对高度计算，关闭不适用的绝对摆足峰值奖励，训练越界终止。训练分布/奖励/预算一起改变，是任务扩展而非单变量因果消融。

## 冻结保留测试

seed138000–138007，原模型与专门续训最终模型使用同一脚本、几何、反馈和任务配对；没有从中间模型挑选结果。所有记录在`<EVIDENCE>`。

| 模型 / 控制接口 | 达标 | 跌倒 | 越界 |
|---|---:|---:|---:|
| 旧粗糙模型＋航向反馈 / 保留集 | 8/8 | 0/8 | 0/8 |
| 专门地形续训30M＋同反馈 / 同保留集 | 8/8 | 0/8 | 0/8 |

旧模型各场景速度RMSE约0.067、0.072、0.063、0.066m/s，全部20秒，最终x约8.03–9.31m。该成绩表明低台阶和缓坡可以由已有策略结合高层反馈完成，不应把旧模型成绩归功于本轮专门续训。

专门续训同反馈8/8，四场景速度RMSE约0.110、0.070、0.046、0.047m/s，最终x约7.32–8.71m。旧模型和续训均全过，不能声称本轮提高通过率；台阶直行误差反而变大，坡面跟踪误差降低。纯yaw-rate开发复测4/8，台阶直行和坡地转向偏离通道，说明航向反馈仍是完整展示的重要组成。两个反馈保留集的evaluator/environment哈希、初始seed和控制方式一致；检查点来源独立保存。

目前单训练seed、小固定8回合；不外推至更高台阶、大坡度、其他路线或真机。视频选每场景首个达标回合，以完整20秒、1×真实时间回放；原始全部8回合指标/轨迹保留。来源见`gpu_course_plan.md`、`gpu_sources.md`和第三方许可证。
