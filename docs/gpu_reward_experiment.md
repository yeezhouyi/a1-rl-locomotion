# A1 GPU 奖励调整开发试验

触发：上游权重的100万步模型与追加1000万步模型独立固定指令评估均0/8达标。实际机体速度与传感器线速度均接近0；站立不是评估器漏读速度。追加模型在转向反转两回合均跌倒。保留原权重路线，新增从随机参数开始的探索分支。

假设：A1适配后，原姿态激励和宽速度容差允许站立获得较高奖励，减少姿态权重、加强速度跟踪可能有助探索行走。该假设尚需用结果验证，不能称已确定根因。

| 参数 | 上游权重 | locomotion_v2 |
|---|---:|---:|
| tracking_lin_vel | 1.0 | 3.0 |
| tracking_ang_vel | 0.5 | 1.0 |
| tracking_sigma | 0.25 | 0.10 |
| pose | 0.5 | 0.1 |
| feet_clearance | -2.0 | -0.5 |
| feet_air_time | 0.1 | 0.3 |

奖励公式、物理、观测、网络保持同一实现。使用1024并行、128 minibatch、8 minibatches、20 unroll，新增约3000万步；配置和实际采样数保存在D盘实验目录。该探索同时改变多个权重和总预算，不能当作单变量等预算因果消融。

验收：沿用开发固定指令集，含各关节±0.03rad初始偏移；若仍失败如实报告。通过后应新增保留测试集和训练seed，避免以开发集调参成绩冒充泛化结论。

实测：30,023,680步训练完成，15M及30M开发集均8/8；冻结30M模型在首次平地保留集8/8达标、0跌倒。粗糙地形迁移暴露失败后追加10,035,200步续训，具体配对结果见`gpu_results.md`。这支持当前配置能学会指令跟踪，但多个奖励权重及预算一起变化，仍不能确定哪个改动导致改善。
