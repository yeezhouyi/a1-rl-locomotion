# 三种子确认实验：四足运动自适应与时序消融

有序历史适应器的平均跟踪成功率为 60.6%，域随机化基线为 55.2%，前者高于后者 5.5 个百分点。固定隐变量为 54.5%；有序适应与固定输入的平均差为 +6.1 个百分点。这些是本轮固定终点、三个训练种子上的结果，不是原论文性能复现或真机验证。

本轮完成 3 个独立初训种子、7 组策略、11 个场景、共 1,155 个配对评估回合。种子 0/1/2 分别从随机网络开始，教师与对应基线共享前 5,000 更新父策略；所有终点检查点在训练前固定。

本轮有序历史在总体均值上高于固定输入和域随机化基线，但仍需查看每个训练种子的差异与全场景结果。三种子的均值改善只能描述为当前仿真设置下的观察，不能推出真机效果或普遍鲁棒性。

打乱历史没有改变任何训练种子的成功回合数，因此当前成功率指标未支持时间顺序必不可少的结论。有序MLP也未优于CNN。固定输入对照的收益集中在seed 0的低摩擦与摩擦突变场景；另两个种子没有同样的成功率改善。

seed 1的基线与教师分支均未完成速度跟踪，部分回合能站满20秒但几乎不前进。它保留在所有聚合统计中，说明当前奖励/优化设置对初始化仍然敏感；本轮未单独操控这些因素，不能将失败原因确认为某一项超参数。

教师与基线累计 PPO 采样相同，但最后阶段教师学习率为 1e-4、基线保持 3e-4，且教师恢复时重置仿真/RNG；两者差异不能单独归因于特权信息。CNN、有序MLP、固定与零输入共享同一个终点教师，可用于判断该教师下适应器是否带来额外控制收益。

CNN 与有序 MLP 都使用 H50（1 秒）历史，参数量相差小于 10%，但结构和优化路径不同，不能把差异只归因于时序信息。打乱历史在推理时改变输入分布，是顺序敏感性诊断。固定隐变量从训练参数分布抽取 4,096 样本后求教师编码均值，不使用测试场景真实参数；零隐变量可能偏离教师训练分布。

参数突变恢复要求速度及偏航误差连续 0.5 秒达标，未恢复包含突变前跌倒。逐种子恢复数与已恢复回合的条件均值见 results.json；不能只报告已恢复回合的时间。推扰目前没有单独恢复时间定义。

## 实现与预算

- Unitree A1、12 关节，45 维本体观测、12 维动作，控制 50 Hz、物理 500 Hz。部署无根部线速度和真实动力学参数输入。
- PPO 包含 GAE、tanh 动作概率修正、梯度裁剪；跌倒不 bootstrap，timeout 使用重置前状态 bootstrap，GAE 不跨回合。
- 每种子 baseline 7,000 更新 / 1,792,000 步；teacher 从自身 baseline_5000 初始化，再 2,000 更新 / 512,000 新步，累计同为 1,792,000。教师最后阶段保持完整随机化范围，初始 actor/critic 与父策略精确相同。
- 每种子两适应器各 750 更新 / 192,000 额外步；各 RMA 分支总预算 1,984,000，超过基线的总预算，不能称总采样预算相同。教师冻结，学生自身轨迹监督隐变量。
- 本轮实际新采样 6,912,000 PPO 步 + 1,152,000 适应步 = 8,064,000 控制步，包含共享父策略节省的训练；每控制步为 10 物理步。
- Windows 原生 MuJoCo 3.3.5、PyTorch 2.8.0+cpu；训练与仿真都在 CPU。硬件含 RTX 4060，但本项目没有 GPU 训练性能结论。
