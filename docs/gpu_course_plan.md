# 坡地与台阶进阶：训练前验收约定

目标是提升真实控制能力，再录制视频；不把既有粗糙地形视频重剪当成任务进阶。

保留Playground/Brax PPO框架及A1控制参数，新增本地MuJoCo实际碰撞几何：6级3.5cm台阶、40cm踏面、总升高21cm，80cm平台后下降；6.84度坡、升高24cm、平台后下坡。横向分三条通道：台阶、平地、坡地。几何没有照抄开源模型；沿用已核验legged_gym分难度/距离验收思路及Playground任务结构，来源见`gpu_sources.md`、`opensource_locomotion.md`。

训练起点覆盖各通道x[-1.5,5.8]，高度按地形表面设置，初始yaw±0.2rad；随机前进指令0.25–0.65m/s及10%停止，侧向±0.03m/s、yaw±0.08rad/s。足端净空改为相对局部地面，关闭不适用于升高地形的绝对z摆足峰值奖励。足端接触传感器统计所有环境碰撞，避免只计算原平面。越出通道或机身离地高度不足终止。

首先以旧粗糙最终模型作固定开发基线，再从其恢复约30M步训练（Adam重新初始化），只选择本分支最终模型。用低台阶起步，不能保证本轮直接推广到更高障碍。512并行/64 minibatch、640约束容量，所有新增结果写D盘。

固定开发集seed127000–127007：台阶直行、台阶变速停走、坡地直行、坡地转向，各2回合。从x=-1.3出发，20秒，无自动重置；需完整存活、未越通道、最终x≥6m、平面速度向量RMSE<0.2m/s、yawRMSE<0.3rad/s才算完成。该条件必须真实跨过上下坡/上下台阶，原地或绕过通道失败。测试噪声0，关节初始±0.03rad。

冻结最终模型后首次保留集seed138000–138007，用相同任务/判据但独立初始扰动，与旧模型配对。只在完整回合后录制；同时保留失败片段，展示具体高度、坡度、速度及单训练seed边界。多种地形/奖励/命令变动属于任务扩展，不是单变量因果消融。

直接迁移原yaw-rate指令开发集0/8、无跌倒、8次偏离通道，暴露累计航向误差。增加可选高层航向反馈：参照固定legged_gym`legged_robot.py`的heading误差转换yaw指令，并增加通道横向误差的目标航向项；本地增益1.5、横向项0.5、yaw限幅±0.4。底层仍为同一PPO策略，不修改动作或物理状态。启用结果必须写“PPO速度策略+高层航向反馈”，与原始yaw-rate独立报告；不得冒充纯策略新增技能。新配对测试两模型都启用同一反馈，记录源码与配置。

航向反馈开发首轮2/8，其余6回合完整穿越障碍但19.4秒左右到达x=9的出口界限。障碍在x=5.8结束，之后是无限物理平面；0.5m/s完整20秒需要约10m前进距离。正式评估出口界限固定x≤12m，横向通道范围、起点、20秒及x≥6m穿越条件保持不变，两模型同条件重测。保留旧出口越界记录；新测试不能冒充旧协议结果。训练出口仍x≤9m以回收环境。
