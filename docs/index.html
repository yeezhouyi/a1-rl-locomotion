实现了哪些强化学习工作

  • 算法实现：CPU PPO / GAE、特权教师、历史适应器、域随机化，以及固定/零隐变量、打乱历史对照。
  • 训练工程：复用 Brax PPO 与固定版本 Playground，完成 A1 观测、PD 控制、地形碰撞和检查点恢复适配。RTX 4060 Laptop 上同步 1,024 环境约 31,585 控制步/秒，仅统计仿真 rollout。
  • 实验诊断：粗糙新空间直接迁移 1/8，追加训练后 7/8，仍有一次跌倒；使用固定评估协议与完整轨迹记录分析失败。

结果边界

这是仿真项目，没有真机部署。GPU 策略未加入 RMA 历史适应器；高层反馈读取仿真 yaw / xy，不代表自主导航。CPU 多种子实验尚未证明 RMA 稳定优于基线。

地形达标要求：完整 20 秒、无跌倒或越界、最终 x ≥ 6 m、平面速度向量 RMSE < 0.2 m/s、yaw-rate RMSE < 0.3 rad/s。纯 yaw-rate 开发集仅 4/8 达标；不能把反馈的效果归因于专门续训，也不能声称续训提高地形通过率。视频采用各场景首个达标回合，全部保留集指标已公开。
