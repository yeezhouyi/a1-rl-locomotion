# Published evidence

These JSON files are copies of measured experiment results. Personal absolute paths were replaced with `<GPU_WORKSPACE>` and `<EVIDENCE>`; metric values, seeds, hashes and configuration values are preserved. This is not a new evaluation run.

Training callbacks count control samples; physics throughput is a different measurement. Each GPU evaluation has 8 episodes and one training seed. The terrain demo uses a high-level heading controller in addition to the PPO policy.

Videos and the representative checkpoint are distributed in the v1.0-demo Release. Full training caches and raw private machine logs are intentionally excluded.
